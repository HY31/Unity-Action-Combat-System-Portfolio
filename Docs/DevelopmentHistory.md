# 개발 과정

초기 공개 커밋과 최종 코드에서 확인할 수 있는 주요 변경을 정리했습니다.

## 1. 기본 전투와 상태 분리

- 이동·기본 공격·회피·피격 처리 구현
- boolean 상태 플래그에서 enum, 상태 객체 기반 구조로 변경
- `IPlayerState`의 `Enter`, `Update`, `Exit`로 행동별 처리 분리

## 2. 데이터 기반 공격과 스킬

- 일반 공격 콤보를 `AttackData`로 관리
- 공격 중 다음 입력을 버퍼에 보관하고 허용 시점에 처리
- 일반·강화 스킬 분기, 궁극기와 데시벨 자원 구현
- `HitPayload`와 실제 공격자 정보가 담긴 `CombatHitData` 분리

## 3. 파티 교대와 지원

- 3인 파티의 활성 캐릭터 교대
- 공격 예고와 지원 포인트에 따른 패링 지원·회피 지원 결정
- 패링 지원의 공격 중단과 그로기 누적
- 극한 회피 이후 일반 공격·스킬 입력 처리

## 4. 판정과 제작 도구

- Body Box와 프레임 사이 무기 궤적 판정
- 물리 검사 버퍼 재사용과 `HashSet` 기반 중복 적중 방지
- 애니메이션과 공격 타이밍을 함께 확인하는 에디터 도구
- 워닝·타격·패링/회피·추적·이동 구간 편집 및 후딜 구간 표시
- 공격 데이터의 누락된 클립과 잘못된 구간·판정 설정 검사

## 5. 강습전 진행

- 보스 패턴 선택과 재사용 가능 시각 관리
- 그로기 진입, 콤보 선택 대기와 실행 처리
- 제한 시간·점수·전투 종료 및 와이프아웃·결과 표시
- 궁극기 영상 재생과 촬영용 Windows 빌드 보조 코드

## 6. 최종 HUD 정리

- 파티 HUD, 상단 보스 HUD와 적 위 상태 표시
- 사다리꼴 게이지와 대각선으로 이동하는 채움 경계
- 물리·얼음 이상 축적 표시
- 디지털 타이머와 점수판
- 데시벨 PTS 표시와 구간별 색상 변화
- 그로기 시간 진행과 콤보 횟수 소진 상태의 HUD 반영

## 공개 저장소 반영 방식

이 저장소의 초기 이력은 원본 개발 이력에서 C# 코드 변경을 선별한 기록입니다. 원본과 공개 저장소의 커밋 해시는 다릅니다.

이번 최종 반영은 기존 공개 이력 위에 최신 소스와 문서를 추가한 것입니다. 원본 저장소의 브랜치를 병합하거나 에셋이 포함된 커밋을 가져오지 않았습니다.

- 포함: 프로젝트 C# 코드, 텍스트 셰이더 소스, Markdown 문서와 Git 설정
- 제외: 모델·애니메이션·이미지·음원·영상, 씬·프리팹·머티리얼·데이터 인스턴스, `.meta`, 외부 플러그인과 Unity 캐시
- 기존 공개 이력과 새 커밋은 위 파일 범위를 기준으로 검사합니다.

이 문서는 코드 확인용 안내입니다. 실행 가능한 Unity 프로젝트나 원작 에셋을 배포하지 않습니다.
