# Development History

이 문서는 코드 커밋 기록에서 확인할 수 있는 구조적 변화를 포트폴리오 관점으로 요약합니다.

## 1. 기본 플레이어 전투

- 이동, 기본 공격과 회피 입력 구현
- 피격 상태 추가
- 초기 boolean 상태 플래그의 한계 확인

## 2. FSM 전환

- 상태를 enum과 `IPlayerState` 기반으로 재구성
- `Enter`, `Update`, `Exit` 생명주기 도입
- 이동, 회피와 피격 타이머를 각 상태로 분리

## 3. 데이터 기반 콤보

- 공격 애니메이션과 수치를 `AttackData`로 이동
- 콤보 인덱스와 다음 공격 연결을 데이터로 구성
- 캐릭터 로직 수정 없이 공격 구성을 바꿀 기반 마련

## 4. HitBox / HurtBox 판정

- 공격자와 피격자의 책임 분리
- 애니메이션 시간에 맞춘 활성 판정
- 타격 정지와 카메라 반응 연결

## 5. 스킬과 궁극기

- 일반·강화 스킬 분기와 자원 소비 추가
- 궁극기 상태와 데시벨 자원 추가
- 여러 `HitWindow`를 이용한 다단 공격 구조 구현

## 6. 패링 지원

- 적 공격 경고와 반응 가능 구간 추가
- 지원 포인트 소비와 패링 지원 상태 구현
- 지원 행동이 현재 파티원과 연결되도록 흐름 확장

## 7. 파티와 캐릭터 데이터

- 3인 파티 교대와 활성 캐릭터 관리
- 스탯, 공격, 스킬과 궁극기 데이터를 캐릭터 단위로 묶음
- 개별 캐릭터 추가 시 컨트롤러 수정 범위 축소

## 8. 제작 파이프라인 자동화

- 캐릭터 프리셋 검증 도구 추가
- 프리팹, 데이터 팩과 Animator 연결 자동화
- 수동 인스펙터 연결 과정에서 발생하는 누락을 검사하도록 개선

## 9. 현재 구조 확장

- `HitPayload`와 `CombatHitData` 분리
- 적의 HP, 그로기, 속성 이상 축적 구현
- 연쇄 스킬 요청 이벤트와 전투 UI 추가
- 적 모델 임포트와 HUD 프리팹 제작 도구 추가

## 공개 기록 정리 방식

원본 개발 저장소의 커밋에서 직접 작성한 `.cs` 변경만 추출했습니다. 따라서 이 저장소에서는:

- 코드가 포함되지 않은 에셋 전용 커밋은 제거됨
- 코드가 포함된 커밋의 작성자, 작성 시점과 메시지는 유지됨
- 모델, 애니메이션, 텍스처, 음향과 영상은 모든 커밋에서 제외됨
- 기록 재작성으로 원본 저장소와 커밋 해시는 달라짐

최신 커밋에는 아직 커밋되지 않았던 현재 개발 코드와 포트폴리오 문서 정리가 함께 반영됩니다.
