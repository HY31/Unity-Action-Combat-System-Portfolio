# 전투 제작용 에디터 도구

반복 재생하며 수치로 맞추던 공격 타이밍을 애니메이션과 함께 확인하기 위한 Unity Editor 도구입니다.

소스: [CombatAttackAuthoringWindow.cs](../Assets/Editor/CombatAttackAuthoringWindow.cs)

## 확인하고 편집하는 항목

| 항목 | 지원 범위 |
| --- | --- |
| 애니메이션 | 재생·정지, 프레임 이동, 플레이헤드 스크럽과 모델 미리보기 |
| 워닝·타격·패링/회피·추적 | 구간 생성·이동·크기 변경·삭제, Undo |
| 이동 | 활성화된 주 공격의 이동 구간 조정. 후속 공격 이동 트랙 편집은 지원하지 않음 |
| 후딜 | 마지막 타격 이후부터 애니메이션 끝까지의 구간 표시. 직접 드래그 편집하는 트랙이 아님 |
| 무기 판정 | 본 이름, 시작점·끝점, 반경과 샘플 수 설정 |
| Scene View | 애니메이션 자세에 맞춘 Body Box와 무기 판정 위치 확인 |
| 데이터 검증 | 클립, 타이밍 구간과 무기 판정 설정 검사 |

## 원본 개발 환경에서의 사용 순서

이 공개 저장소에는 아래 작업에 필요한 씬·모델·애니메이션·데이터 인스턴스가 없습니다. 실행 절차는 해당 자료를 갖춘 원본 개발 환경 기준입니다.

1. `EnemyAttackData`를 선택하고 `Tools > Combat > Attack Authoring`을 엽니다.
2. 씬의 Enemy Animator와 공격 클립을 확인합니다.
3. 애니메이션을 스크럽하며 타이밍 구간을 조정합니다.
4. Body Box 또는 Weapon Sweep의 위치와 활성 구간을 확인합니다.
5. `Tools > Combat > Validate All Enemy Attacks`로 데이터 설정을 검사합니다.

편집 도구와 런타임은 동일한 `EnemyAttackData`를 사용합니다. 미리보기에서 확인한 타이밍을 별도의 런타임 데이터로 다시 옮길 필요가 없도록 구성했습니다.
